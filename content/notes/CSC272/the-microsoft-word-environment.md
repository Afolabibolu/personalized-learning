# The Microsoft Word Environment

## Starting Word

Opening Word 2013 shows the **Start Screen**, a new feature of Office 2013: **recently opened documents** on the left and **templates** (letters, labels, reports, flyers) on the right. Most people choose **Blank document**. Word names a new document **"Document1"** and shows it in **Print Layout**, the default view.

## Views

Word's views are **Print Layout** (the default, showing the document as it will print), **Read Mode**, **Web Layout** (as a web page), **Outline** (simplifies formatting to show the document's structure) and **Draft** (designed for fast entry and editing; called Normal view in earlier versions). The **Zoom** control enlarges the page on screen without changing the font size.

## The File tab

The **File tab** replaces the old file menu, with **Open, Close, Save, Save As, Print**, New, Export and Share. Its **Info** menu holds **Protect Document**, which can **encrypt** a document with a password (use with caution: a forgotten password means the data cannot be recovered), **restrict access**, **Mark as Final** (makes the document read-only to show it is complete, though the recipient can remove it, so it is **not a security feature**) and add a **digital signature**. **Inspect Document** checks for issues that may cause problems in earlier versions of Word.

## The Ribbon

The **Ribbon** has three basic components: **tabs** (seven basic ones across the top, each an activity area, such as HOME), **groups** of related items within each tab (such as Font), and **commands** (a button, icon, box or menu). Resting the mouse on a command shows its name and what it does. A small arrow at the bottom right of a group is the **dialog box launcher**, which opens more options.

- **Home**: Font group (font, size, bold, italic, superscript, subscript, **Change Case**), **Clipboard** (cut, copy, paste and **Format Painter**, which copies formatting from one paragraph to another), Paragraph (bullets, alignment, line spacing, sorting and the **Show/Hide ¶** paragraph mark, which reveals non-printing characters), Styles and Editing (Find, Replace).
- **Insert**: cover pages, page breaks, tables, pictures, SmartArt, headers and footers, and the **Equation** tool.
- **Design**: themes, **watermarks** (faint background text such as "Confidential") and page borders.
- **Page Layout**: margins, orientation, paper size, **breaks** and **columns**.
- **References**: table of contents, footnotes, index and bibliography.
- **Mailings**: **mail merge**, for sending the same letter with small changes to many people, and envelopes and labels.
- **Review**: spelling, thesaurus, word count and **Track Changes**.
- **View**: ruler, gridlines, split windows and **View Side by Side**.

**Contextual tabs**, in distinctive colours, appear only when needed: selecting a picture shows **Picture Tools**, and the same happens for tables, shapes, SmartArt and charts.

## The Quick Access Toolbar

The **Quick Access Toolbar**, at the top left, is customisable and **stays the same whichever tab is open**. By default it holds **Save, Undo and Redo**; right-click a command and choose "Add to Quick Access Toolbar" to add it.
