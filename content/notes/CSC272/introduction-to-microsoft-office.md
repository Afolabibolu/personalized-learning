# Introduction to Microsoft Office

## The course and the suite

CSC 272 is a service course on using common applications to **store data, analyse it into information and present that information** to an audience. It uses the **Microsoft Office suite** because it is the most common suite for preparing and managing data and comes pre-installed on most computers. **OpenOffice** is an open-source alternative, and files made in either can be modified with the other. The suite includes Access, Excel, Word, PowerPoint, Outlook and Project; the course covers the **first four**. Assessment is **60% examination and 40% continuous assessment**.

## Microsoft Word

**Word** is a **graphical word processing program** for typing and saving text, tables, graphics and charts. A Word file is called a **document**, saved with the extension **.doc**, or **.docx** in newer versions. Its tools include a choice of typefaces, word counting, synonyms and a **thesaurus**, pictures and tables, a **spelling and grammar checker**, and **tracking of changes**. Add-ons such as Grammarly can be used too.

## Microsoft Excel

**Excel** is a **spreadsheet application**: a tool for maintaining, analysing and calculating sets of information arranged in **rows and columns** and manipulated with arithmetic operations and functions. An Excel file is called a **workbook**, because it usually contains several **worksheets**, and is saved as **.xls** or **.xlsx**. Excel also offers programming through **Visual Basic for Applications (VBA)**, access to external data through **Dynamic Data Exchange (DDE)**, and extensive charting. It is used for number crunching, charts, storing and importing data, automation and analysis in statistics, finance, inventory and business intelligence.

## Microsoft Access

**Access** is **database software** that stores information for **reference, reporting and analysis**. It manages large amounts of related data faster and more efficiently than a spreadsheet, for example a library's books and who borrowed which one. It is known for its **tables, forms and queries**, called its "objects". An Access file is called a **database**, saved as **.mdb** or **.accdb**.

## Microsoft PowerPoint

**PowerPoint** designs **presentation slides** for reporting results in a concise, attractive and graphical way, with fewer words and a straight-to-the-point approach. A PowerPoint file is called a **presentation**, saved as **.ppt** or **.pptx**. It can plot simple charts, insert pictures and videos, and apply special effects and backgrounds.

## Which application?

Use **Access** when large amounts of data must be collected and organised for easy retrieval, reporting and analysis; **Excel** for mathematical manipulation of data; **Word** for typing and formatting documents; and **PowerPoint** for presenting information to an audience. Each application's window has a name (title) bar, status bar, ribbon and Quick Access Toolbar, although the tools vary from one application to another.
