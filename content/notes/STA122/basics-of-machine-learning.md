# What Machine Learning Is

## Definition

**Machine learning (ML)** is teaching computers to **learn from data** the way we learn from experience. It is a **subfield of artificial intelligence (AI)**: a system learns patterns from data to make decisions, as when an email filter learns to recognise spam.

A formal definition (Tom Mitchell): a program **learns from experience E** with respect to a class of **tasks T** and a **performance measure P** if its performance at T, as measured by P, improves with E. For a spam filter:

- T is labelling emails;
- E is a collection of emails already marked spam or not;
- P is the percentage labelled correctly.

## Related terms

- **Data science**: extracting insights from data using ML, statistics and other tools.
- **Data mining**: discovering hidden patterns in large datasets.
- **Data analysis**: cleaning, transforming and modelling data.
- **Statistical learning**: using statistical methods to learn from data.
- **KDD**: Knowledge Discovery in Databases.
- **Pattern discovery**: finding recurring trends or regularities.

ML is **interdisciplinary**, drawing on statistics, mathematics, computer science (databases), engineering, signal processing, visualisation, biology and economics.

## Data everywhere

The world's data volume grew from about **2 zettabytes in 2010 to about 181 ZB in 2025** (1 ZB is a trillion gigabytes). Data come as:

- texts (emails, tweets);
- numbers (prices, temperatures);
- clickstreams;
- graphs (social networks);
- tables;
- images (selfies, medical scans);
- transactions;
- videos.

Smartphones, browsing and social media leave data trails about us, so **privacy** is a growing concern.

## The data science process

1. **Data collection**, using domain expertise.
2. **Data preparation**: cleaning, and feature (variable) engineering.
3. **Exploratory data analysis (EDA)**: descriptive statistics, clustering and research questions.
4. **Machine learning**: classification, scoring, predictive models, clustering.
5. **Visualisation**: dashboards and deployment, so that decisions are based on the data. The cycle then repeats with new data.
