# Presentation of Data

## Tables

**Tabulation** arranges data in rows and columns, as in a timetable. It simplifies large data sets and allows comparison. **Classification** groups data into classes so that **each item belongs to exactly one class**.

## Frequency distributions

A **frequency distribution table** shows how often each value or class occurs. To construct one:

1. Find the **range** (largest − smallest).
2. Choose the number of classes and the **class width** (about range ÷ number of classes).
3. Write **non-overlapping** class intervals.
4. Tally and count the frequencies.

The key terms:

- **class limits**: the smallest and largest values written for a class, such as 10–19;
- **class boundaries**: halfway between adjacent limits, 9.5–19.5, which close the gaps;
- **class mark (midpoint)**: (lower + upper)/2;
- **class width**: upper boundary − lower boundary;
- **relative frequency**: f/Σf, often as a percentage;
- **cumulative frequency**: the running total, used for the ogive and for medians and quartiles.

## Diagrams

- **Line diagram**: data over time.
- **Bar chart**: equal-width bars for categories. A **simple** bar chart shows one variable; a **multiple** chart puts bars side by side; a **component** chart splits a bar into parts.
- **Pictogram**: pictures represent quantities.
- **Pie chart**: sectors with angles **(f/Σf) × 360°**.
- **Histogram**: adjacent bars for grouped continuous data, with **area proportional to frequency**.
- **Frequency polygon**: joins the midpoints of the tops of histogram bars.
- **Ogive**: the cumulative frequency curve, from which the median and quartiles are read.
- **Stem-and-leaf display**: splits each value into a stem (leading digits) and a leaf (last digit). It shows the shape and keeps the raw data: for 23, 25 and 31, the stem 2 has leaves 3 and 5, and the stem 3 has leaf 1.

Choose the chart to suit the data: pie and bar charts for categories, histograms for continuous data.
