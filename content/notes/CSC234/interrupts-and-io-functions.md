# Interrupts and Input/Output Functions

## Interrupts

An **interrupt** is a signal that **gets the attention of the CPU**, usually generated when I/O is required. **Hardware interrupts** are generated when a key is pressed or the mouse moves; **software interrupts** are generated by a program that needs, for example, disk input or output. The course deals with software interrupts, which can be seen as a set of **functions**: instead of writing code to print a character, you simply call the interrupt and it does the work. Interrupts give the user better control over the computer.

The syntax is **INT value**, where the value is a number from 0 to 255 (00h to FFh). Many interrupts have **sub-functions**, selected by putting a number in the **AH** register before the INT instruction.

- **INT 10h** provides video (screen) services. Sub-function **0Eh** gives **teletype output**: put 0Eh in AH and the ASCII code of a character in AL, and INT 10h prints it and advances the cursor; repeating this prints a message like "Hello!". INT 10h with other sub-functions sets the video mode.
- **INT 11h** returns the **BIOS equipment list**.
- **INT 21h** provides DOS services. With **AH = 1** it **reads a character from standard input** and stores it in **AL**, waiting if no key is in the keyboard buffer. With **AH = 2** it **writes the character in DL** to standard output; afterwards AL = DL.

When INT calls an interrupt, it stores the flags register, the code segment and the offset on the stack, and **IRET** returns from the interrupt.

## Common functions in emu8086

The emu8086 include file **emu8086.inc** provides ready-made macros and procedures:

- **PUTC** (a macro with one parameter) prints an ASCII character at the current cursor position.
- **GOTOXY** (a macro with two parameters) sets the cursor position (row and column).
- **PRINT** (one parameter) prints a string, which must be in quotes; **PRINTN** does the same and then moves to a new line.
- **SCAN_NUM** reads a multi-digit number from the keyboard into CX.
- **PRINT_NUM** prints a signed number in AX (and PRINT_NUM_UNS an unsigned one).

These let programs read numbers, compare them and display results, for example checking whether two numbers typed at the keyboard are equal.
