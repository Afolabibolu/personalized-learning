# Website Design, UI/UX and Responsive Design

## Website design

**Website design** is the process of **planning, conceptualising and arranging content** for the Internet, creating sites that are **visually appealing, functional, user-friendly and accessible** across devices. A good design is attractive, **loads quickly**, is easy to navigate, works on different devices and meets users' needs.

## Principles

1. **Simplicity**: avoid unnecessary elements; clean layouts, minimal clutter and clear navigation, as on **Google's homepage**.
2. **Consistency**: uniform fonts, colours, buttons, menus and layouts across all pages, which improves usability and builds trust.
3. **Visual hierarchy**: arrange elements by **importance**, with larger headings, bold text and contrast; the page title should be larger than subheadings, which are larger than body text.
4. **Balance**: distribute elements evenly. **Symmetrical** balance arranges elements evenly on both sides (corporate sites); **asymmetrical** balance balances different-sized elements creatively (portfolio sites).
5. **Contrast**: make important information stand out, such as a bright "Buy Now" button on a dark background.
6. **White space (negative space)**: empty space between elements, which improves readability and reduces clutter.
7. **Accessibility**: usable by everyone, including people with disabilities, with **alt text** for images, keyboard navigation, sufficient colour contrast, readable fonts and captions.
8. **Performance**: improved by compressing images, optimising code, reducing animations and **caching**.

## UI and UX

The **user interface (UI)** is **everything users interact with**: buttons, menus, icons, forms, navigation bars, typography and colours. A good UI is attractive, consistent, easy to understand, interactive and responsive. **User experience (UX)** is the **overall experience** of using the site: ease of use, efficiency, **satisfaction** and accessibility. UI focuses on **appearance**; UX on **experience**. They work together: a shopping site with beautiful product cards (good UI) but a confusing checkout (poor UX) still fails its users.

## Responsive web design

**Responsive web design (RWD)** lets a site **adapt automatically to different screen sizes**: phones, tablets, laptops, desktops and smart TVs. It matters because most users browse on phones, it improves UX and search rankings, and one site serves all devices. Its features are:

- **flexible layouts** and **flexible images**;
- **CSS media queries**, such as `@media (max-width:768px) { body { font-size:16px; } }`;
- **responsive navigation**, where a full menu becomes a ☰ menu on phones; and
- responsive typography.

Typical widths are mobile up to 767px, tablet 768 to 1023px, laptop 1024 to 1439px and desktop 1440px and above. Best practice: **design for mobile first**, use flexible grids, optimise images, test on many devices, make buttons easy to tap and **avoid fixed-width layouts**. Design tools include **Figma**, Adobe XD and Sketch; development tools include Chrome DevTools, **Bootstrap** and **Tailwind CSS**.
