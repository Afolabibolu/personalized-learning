# Introduction to Web Development

## Web development

**Web development** is the process of **designing, building, deploying and maintaining websites and web applications** accessed through the Internet or an organisation's intranet. A **website** consists of interconnected web pages stored on a web server and reached through a browser with a **URL**. Modern web development combines programming, databases, networking, UI design, security and software engineering.

The **World Wide Web** is an information space where documents are identified by URLs, interlinked by hypertext and accessed via the Internet. It was invented in **1989 by Tim Berners-Lee at CERN**, and relies on HTTP/HTTPS, URLs, HTML, browsers and web servers. The **Internet** is a **global network of computers**, an **infrastructure** supporting email, FTP, VoIP and the Web; the **Web** is a **service** that runs on it and uses HTTP/HTTPS.

## Evolution of the Web

- **Web 1.0, the read-only Web**: static HTML pages for publishing information, with no user interaction.
- **Web 2.0, the read-write Web**: dynamic sites, **user-generated content**, social media, blogs and online shopping (Facebook, YouTube, Wikipedia), using PHP, JavaScript, AJAX and MySQL.
- **Web 3.0, the semantic and intelligent Web**: AI, personalisation, linked data, APIs and blockchain, as in chatbots and recommendation systems.

## Sites and applications

A **website** primarily **provides information**, is mostly static with minimal interaction and usually needs no login (a university homepage). A **web application** **performs tasks**, is dynamic and interactive, and usually requires a **login** (a student portal).

- A **static website** stays the same until manually changed. It uses HTML and CSS only, with no database, so it is fast, cheap and secure, but hard to update and offers no personalisation.
- A **dynamic website** **generates pages automatically** using server-side programming and **databases**, as Facebook, Amazon and banking systems do. It allows easy updates, authentication and interactivity, but is more complex and needs more hosting.

## Frameworks

A **framework** is a collection of **reusable components, libraries, tools and best practices** that simplify development. Its benefits include faster development, reusable code, better organisation and security, built-in authentication and **database abstraction**. Examples are **Laravel, CodeIgniter, Symfony and Yii** (PHP), **Django, Flask and FastAPI** (Python) and **ASP.NET** (C#).

## Client and server

**Client-side** code runs **in the browser** (HTML, CSS, JavaScript) and handles the interface, interaction, validation and animation. **Server-side** code runs **on the web server** (PHP, Python, Java, ASP.NET) and handles **business logic, authentication, database access and security**. A web developer needs front-end, back-end, database, security, testing, deployment, version control and API skills. Web applications follow the **software development lifecycle**: requirement analysis, system design, development, testing, deployment and maintenance.
