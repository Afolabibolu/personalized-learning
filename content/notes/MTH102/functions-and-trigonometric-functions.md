# Functions and the Circular Functions

## Functions

A **function** f gives each input x exactly one output y. It can be described completely by its **rule**, its **graph** or the **set of ordered pairs** (x, y). x is the independent variable and y the dependent one.

- f is **one-to-one (injective)** if (x₁, y₀) and (x₂, y₀) in f imply x₁ = x₂. Its advantage is that swapping x and y still gives a function, the **inverse** f⁻¹.
- A **continuous** function's graph can be drawn without lifting the pen.
- A **polynomial** of degree n is aₙxⁿ + ... + a₀ with aₙ ≠ 0. A **rational function** is P(x)/Q(x).
- Functions combine as (f + g)(x) = f(x) + g(x), (fg)(x) = f(x)g(x) and (f/g)(x) = f(x)/g(x). The **composition** (f ∘ g)(x) = f(g(x)): with f(x) = √(x − 1) and g(x) = √(x + 1), f ∘ g(x) = √(√(x + 1) − 1).

The **domain** is where the rule makes sense: x/(x² + 1) is defined for all real x.

## Circular functions

For a point P = (x, y) on the unit circle with OP at angle θ to the positive x-axis, **sin θ = y** and **cos θ = x**, so **−1 ≤ sin θ ≤ 1**. Anticlockwise angles are positive. **360° = 2π radians**.

A function is **periodic with period p** if f(x + p) = f(x) for all x, taking the smallest positive p. Sine and cosine have period **2π**: sin θ = sin(θ + 2πn) for every integer n. So sin 750° = sin 30° and sin(−450°) = sin 270°.

- **tan θ = sin θ/cos θ = y/x**, with period π. It has **asymptotes where cos θ = 0**, at θ = π/2 + nπ.
- **cosec θ = 1/sin θ**, **sec θ = 1/cos θ** and **cot θ = 1/tan θ**.

A function is **odd** if f(−x) = −f(x); **sin is odd**, since sin(−θ) = −sin θ. It is **even** if f(−x) = f(x); **cos is even**.

Shifts follow from the graphs: cos(θ − π) = −cos θ, sin(3π/2 − θ) = −cos θ and cos(π/2 + θ) = −sin θ.

Exact values: sin π/4 = √2/2, sec π/6 = 2/√3, tan π/3 = √3 and cos π/3 = ½.

The period of a sum, such as sin(x/2) + sin(x/3), is the lowest common multiple of the separate periods: 4π and 6π give **12π**.
