# Inequalities

## Notation

**a < x < b** is the open interval **(a, b)** and **a ≤ x ≤ b** the closed interval **[a, b]**. Half-open intervals are [a, b) and (a, b]. x > a is (a, ∞), and the whole line is (−∞, ∞) = ℝ.

- "Or" gives a **union**: (2 < x < 5) or (3 < x < 7) is (2, 7).
- "And" gives an **intersection**: [−2, 5] ∩ (1, 7) = (1, 5].

## Properties

1. **Transitive**: a < b and b < c imply a < c.
2. Adding or subtracting the same number keeps the sign.
3. Multiplying or dividing by a **positive** number keeps the sign.
4. Multiplying or dividing by a **negative** number **reverses** the sign: 2 < 5 but −2 > −5.
5. If c ≠ 0 then c² > 0. ab > 0 means a and b have the same sign; ab < 0 means opposite signs.

**Example**: 3x/4 + (1 − x)/3 > 3x − 5. Multiply by 12 to get 5x + 4 > 36x − 60, so −31x > −64 and **x < 64/31**. **Example**: 3 < 3 − 4x < 7 gives 0 < −4x < 4, so −1 < x < 0.

## Absolute values

|x| is x if x ≥ 0 and −x if x < 0. |xy| = |x||y|, and the **triangle inequality** is **|x + y| ≤ |x| + |y|**.

- **|x| < a** means **−a < x < a**: |1 − 4x| ≤ 5 gives −1 ≤ x ≤ 3/2.
- **|x| > a** means **x > a or x < −a**: |3x + 2| > 5 gives x > 1 or x < −7/3.

## Quadratic and cubic inequalities

Find the **critical values** where each factor is zero. They split the line into segments, and a **sign table** gives the sign of each factor in each segment. Multiply the signs to read off the answer.

- (5x + 2)(x + 4) < 0: the critical values are −4 and −2/5, and the product is negative in the middle, so **−4 < x < −2/5**.
- (3 + x)(4 − x) ≤ 0 gives **x ≤ −3 or x ≥ 4**.
- (x + 1)(x − 1)(x − 2) < 0 gives **x < −1 or 1 < x < 2**.
- (x + 1)(x − 2)(x − 3) is positive for −1 < x < 2 or x > 3.

The graph also works: y = ax² + bx + c is a parabola opening up if a > 0.

## Proving inequalities

Rearrange to a perfect square or a product of non-negative factors: a⁴ + b⁴ − 2a²b² = (a² − b²)² ≥ 0, so **a⁴ + b⁴ ≥ 2a²b²**. Adding three such results gives a⁴ + b⁴ + c⁴ ≥ a²b² + b²c² + c²a².
