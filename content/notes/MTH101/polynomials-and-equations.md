# Polynomials and Polynomial Equations

## Polynomials

A real polynomial of degree n is **f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀**, with aₙ ≠ 0 the **leading coefficient** and a₀ the constant term. Degrees 1 to 5 give **linear, quadratic, cubic, quartic and quintic** functions. Polynomials are added, subtracted, multiplied and divided like numbers. f(x) can be divided by g(x) if the degree of g is not greater than that of f, and then **f(x) = d(x)·q(x) + r(x)**: divisor × quotient + remainder. For example, x³ + 3x² − x + 1 = (x − 2)(x² + 5x + 9) + 19.

## Remainder and factor theorems

- **Remainder theorem**: when f(x) is divided by **ax + b**, the remainder is **f(−b/a)**. Dividing f(x) = 6x³ + 2x² − 1 by x + 1 gives remainder f(−1) = −5.
- **Factor theorem**: ax + b is a factor of f(x) **if and only if f(−b/a) = 0**. For x⁴ − 15x² + 10x + 24, f(2) = 16 − 60 + 20 + 24 = 0, so x − 2 is a factor.

## Linear equations

ax + b = 0 (a ≠ 0) has one root, **x = −b/a**. y = ax + b is a straight line with slope a and y-intercept b. Exponential equations can reduce to linear ones: 8^(x+1) = 4^(x+3) gives 3(x + 1) = 2(x + 3), so x = 3.

A pair of **simultaneous linear equations** is solved by substitution, elimination, Cramer's rule or graphs. It has a **unique solution** (lines that cross), **infinitely many** (the same line, as with 4x + 2y = 8 and 12x + 6y = 24) or **none** (parallel lines).

## Quadratic equations

Completing the square on ax² + bx + c = 0 gives **x = (−b ± √(b² − 4ac))/2a**. The **discriminant D = b² − 4ac** decides the roots:

- **D > 0**: two different real roots (x² + 3x + 2 = 0);
- **D = 0**: equal roots (x² + 6x + 9 = 0);
- **D < 0**: no real roots, only imaginary ones (3x² + 2x + 5 = 0, D = −56).

For roots α and β, **α + β = −b/a** and **αβ = c/a**, and the equation is x² − (α + β)x + αβ = 0. Useful identities are **α² + β² = (α + β)² − 2αβ** and α³ + β³ = (α + β)³ − 3αβ(α + β). For 3x² − 4x − 5 = 0, α² + β² = 16/9 + 10/3 = **46/9**.

## Cubic equations

For ax³ + bx² + cx + d = 0 with roots α, β and γ: **α + β + γ = −b/a**, **αβ + βγ + γα = c/a** and **αβγ = −d/a**.
