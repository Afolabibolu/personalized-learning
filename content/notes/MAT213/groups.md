# Algebraic Systems and Groups

## Binary operations

A **binary operation** ∗ on a set S is a function S × S → S, and (S, ∗) is an **algebraic system**. The operation is **closed** if a ∗ b ∈ S for all a, b. (N, +) and (N, ×) are closed but (N, −) and division are not. ∗ is **commutative** if a ∗ b = b ∗ a, **associative** if a ∗ (b ∗ c) = (a ∗ b) ∗ c, and **distributive** over ∘ if a ∗ (b ∘ c) = (a ∗ b) ∘ (a ∗ c); × is distributive over +. Subtraction and division are neither commutative nor associative.

An **identity** e satisfies a ∗ e = a = e ∗ a and must be unique: 0 for addition and 1 for multiplication, while subtraction and division have none. An **inverse** x⁻¹ satisfies x ∗ x⁻¹ = e: in (Z, +) it is −x, in (R − {0}, ×) the reciprocal, and in (N, +) there is none.

## From groupoid to group

- A **groupoid** is a set closed under ∗.
- A **semigroup** is an associative groupoid.
- A **monoid** is a semigroup with an identity, such as (Z∗, ·).
- A **group** is a monoid in which every element has an inverse; equivalently it satisfies **closure, associativity, identity and inverse**.

A group is **commutative (abelian)** if a ∗ b = b ∗ a. (R, +), (R − {0}, ×) and ({1, −1, i, −i}, ×) are groups. (N ∪ {0}, +) is **not** a group because positive integers have no inverse in it.

## Cyclic groups, order and subgroups

⟨a⟩, all powers of a and their inverses, is the subgroup generated by a; if G = ⟨a⟩, G is **cyclic**. Z₃ = ⟨1⟩ = ⟨2⟩. The **order** |G| is the number of elements, and the **order of an element** o(x) is the least positive n with xⁿ = e: in (Z₄, +₄), o(3) = 4 and o(2) = 2. H is a **subgroup** of G if (H, ∗) is itself a group; this holds when a ∗ b⁻¹ ∈ H for all a, b ∈ H. {e} and G are the trivial subgroups. By **Lagrange's theorem**, the order of a subgroup of a finite group divides the order of the group.

## Homomorphisms and permutations

f : (G, ∗) → (S, ∘) is a **homomorphism** if f(a ∗ b) = f(a) ∘ f(b). An injective homomorphism is a **monomorphism**, a surjective one an **epimorphism**, a bijective one an **isomorphism**, a homomorphism into itself an **endomorphism**, and a bijective endomorphism an **automorphism**. A bijection ρ : X → X is a **permutation**; a set of n elements has n! of them, forming the **symmetric group Sₙ** under composition. |S₃| = 6, and composition of permutations is not commutative.
