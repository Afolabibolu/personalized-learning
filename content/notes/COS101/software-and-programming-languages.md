# Software and Programming Languages

## Software

A **software program** is a sequence of instructions for the CPU to carry out a task. Software falls into **two major categories**: **system software** and **application software**.

## System software

**System software** makes the computer usable for developers and users. It includes the **operating system**, **language translators**, the **linker**, the **loader** and **preprocessors**. The **operating system (OS)** is an organised collection of programs that serves as the **interface between the user or application and the computer**. It manages hardware resources:

- **CPU management**, sharing processor time between processes;
- **memory management**, allocating memory dynamically;
- **I/O management**, handling reading and writing devices.

**DOS** is loaded from disk and uses a **command-line interface**: users must memorise and type commands. **Microsoft Windows** is a **graphical user interface (GUI)** that allows **multitasking**. Other systems include IBM OS/2, Mac OS, Unix and **Linux**. A **utility program** helps analyse, configure, optimise and maintain the computer, for example a virus scanner or disk defragmenter.

## Application software

**Application software** is developed to solve specific problems, such as word processing, accounting or library management.

- **General-purpose office software**: word processing (MS Word), spreadsheets (Excel), database management (MS Access, Oracle) and presentation software (PowerPoint), which creates slide shows.
- **Special-purpose software**: desktop publishing (Publisher), imaging and drawing (CorelDRAW, Photoshop) and library management.

A **software update** is a revised version that fixes known problems and adds enhancements.

## Programming languages

A **programming language** is an agreed format of symbols for instructing a computer. It supports variables, expressions, assignment, input and output, loops and decisions.

- **Machine language** is the computer's natural language: binary strings of 0s and 1s. It needs no translation, but it is **machine-dependent**, so programs are **not portable**.
- **Assembly language** uses English-like abbreviations (L 1, GROSSPAY). An **assembler** translates it, and each instruction usually matches one machine instruction, so programs are long and not portable.
- **High-level languages** are English-like: one statement (Netpay = gross pay − tax) does many machine operations. A **compiler** translates the source program into an object program. Examples:
  - **COBOL** for business;
  - **FORTRAN** for mathematics;
  - **Pascal**, a structured language;
  - **C**, procedure-oriented, used for operating systems and compilers;
  - **Java**, object-oriented;
  - **C++**, C extended to support object orientation.

Languages are also classed by generation: machine language is 1GL, assembly 2GL, high-level 3GL and fourth-generation languages 4GL.
